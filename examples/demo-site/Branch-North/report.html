Executive summary

Branch North scored 58/100 (grade D) across internet exposure, rule base, device hardening, logging and inspection, VPN and objects. 4 high-severity issues need prompt attention, including: Management exposed on internet-facing interface; REST API user without trusted hosts; FortiOS version is past end of support.

4 services are reachable from the internet. 6 of 13 rules (46%) are unused, redundant, shadowed, expired or disabled and are candidates for removal, and 4 objects are unreferenced.

The firewall runs FortiOS 7.2.10, whose branch reached end of support on 2026-09-30: Fortinet no longer fixes its vulnerabilities, so upgrading is the first priority.

Against the FortiGate best-practice baseline (Fortinet, CIS and the Canadian Cyber Centre), 6 of 33 assessed practices are met, 3 partly and 24 not; 8 of the gaps can be closed with a single setting each.

The weakest area is device hardening (18/100). The actions below are ordered by risk; the remediation appendix contains ready-to-review FortiOS commands for most of them.

No usage data (offline config without --usage): zero-hit and stale-rule checks are skipped.

# [MEDIUM] Admin GUI accepts TLS older than 1.2: admin-https-ssl-versions is tlsv1-1 tlsv1-2 tlsv1-3.

    set admin-https-ssl-versions tlsv1-2 tlsv1-3

# [LOW] Weak admin lockout: Admins are locked out after 3 failed attempts for 60 seconds (the default).
config system global
    set admin-lockout-threshold 3
    set admin-lockout-duration 900
end

# [LOW] No admin password policy: Password policy is disabled.
config system password-policy
    set status enable
    set apply-to admin-password
    set minimum-length 12
    set min-lower-case-letter 1
    set min-upper-case-letter 1
    set min-number 1
    set min-non-alphanumeric 1
end

# [LOW] Time synchronization disabled: ntpsync is disable.
config system ntp
    set ntpsync enable
end

# [LOW] Static-key TLS ciphers allowed: ssl-static-key-ciphers is enable.
config system global
    set ssl-static-key-ciphers disable
end

# [LOW] USB auto-install enabled: auto-install-config and auto-install-image enabled.
config system auto-install
    set auto-install-config disable
    set auto-install-image disable
end

# [LOW] Rule uses an expired schedule: #60 'promo-access' uses schedule 'promo-2024', which has ended.
config firewall policy

end
